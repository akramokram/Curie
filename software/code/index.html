Required for reminders and task completion
How do I get this? (the hard one) →
  1. Go to Google Cloud Console and create a new project.
  2. Under APIs & Services → Library, enable the Google Calendar API.
  3. Under APIs & Services → OAuth consent screen, set it to External and add your own email as a test user.
  4. Under Credentials, create an OAuth Client ID of type Desktop app. Copy the Client ID and Client Secret.
  5. Run the included get_google_refresh_token.py script on your computer with those two values — it opens a browser, you sign in and grant calendar access, and it prints a Refresh Token.
  6. Paste all three values above.

Full walkthrough with screenshots: see the project write-up.
